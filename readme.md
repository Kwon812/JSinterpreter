## 기능구현
1. const, let 변수선언 구현
2. 조건문 구현 (if)
3. 함수 구현 (func)
4. 출력 구현 (print)
5. 반복문 구현 (for to , while)
6. 변수 스코프 구현( EnvsController )
## 설계
1. 문자열 입력
   - main.text 파일
2. 토큰화
   - Token class , 
     - 정규식 이용 -> 파싱 ('let a=10' -> ['let','a','=','10'])
3. Ast 파싱
   - AstParser class
     - parse keyword (let, const, if, func, print, for to, while)
     - parse value (number, string ,binary, identifier)
     - parse block ( {} )
     - parse params 
     - parse from to
     - parse binary 
4. 실행
   - Env class
     - 변수 상태 관리 ( 이름, 키워드, ...)
   - EnvsController class
     - 변수 스코프 관리-> 스택구조 ->지역,전역 변수 관리
   - Run class
     - ast 를 타입별로 실행
